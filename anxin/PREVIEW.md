# 本地预览

在仓库根目录运行 `python app.py`，然后打开 <http://127.0.0.1:5000/login>。首次运行会初始化本地演示数据库和体验账号。

## 演示账号

| 账号 | 角色 |
|---|---|
| `admin_demo` | 超级管理员 |
| `community_demo` | 社区管理员 |
| `volunteer_demo` | 志愿者 |
| `family_demo` | 家属 |
| `elder_demo` | 老人 |

统一演示密码：`Anxin2026!`。密码在数据库中以哈希形式保存；角色与数据范围由服务端账户决定。

## 建议体验

1. 用超级管理员账号进入系统管理，查看账号角色、权限、日志、CSV 导入导出和备份入口。
2. 用社区管理员账号查看本社区老人、设备、服务和预警工单。
3. 在场景模拟器生成预警，派给志愿者，再用志愿者账号完成到场、服务回执和归档。
4. 用家属账号查看已绑定老人的预警进展和站内消息。
5. 用老人账号体验报平安和紧急求助页面。

预警与工单支持依据展示、同类未关闭预警合并、派单、转派、催办、到场、回执、关闭及处理时间线。管理员可查看设备历史读数、维护通知模板并配置自动备份间隔。

## 数据与安全边界

- 社区管理员的数据范围受所属社区约束；志愿者只能查看和处理分配给自己的任务；家属和老人仅能访问绑定关系内的数据。
- 审计日志面向查询和导出，不提供普通管理员修改或删除入口；重要数据通过归档、软删除或备份恢复减少误操作风险。
- 这是本地功能演示，不连接真实传感器、短信、电话或救援系统。演示数据库可删除后重新初始化；不要将演示账号用于生产环境。
